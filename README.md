# 🇩🇪 Wortyfi_DeutschLernen — PWA Тренажер німецьких слів з ШІ та Хмарою

Сучасний, безкоштовний веб-додаток для вивчення німецьких слів із використанням штучного інтелекту Google Gemini та миттєвою хмарною синхронізацією через Firebase.

## 🚀 Можливості
- **Картки Лейтнера (Spaced Repetition):** 5 рівнів засвоєння слів.
- **Генератор ШІ (Gemini 3.8 Flash):** Автоматичний підбір слів вибраного рівня (A1-C1) та тематики.
- **Синхронізація між пристроями:** Автоматично оновлює словник і прогрес між ПК та телефоном через Google Firebase.
- **Тренажери:** Квіз з перевіркою написання та гра «З'єднай пари».

---

## 🛠️ Як підключити власну хмару та ШІ (для форків / користувачів)

1. Відкрийте додаток і натисніть іконку **Налаштувань ⚙️** у правому верхньому кутку.

2. **Підключення ШІ (Gemini API):**
   - Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Вставте його в поле `Google Gemini API Key`.

3. **Підключення миттєвої синхронізації (Firebase):**
   - Зайдіть на [Firebase Console](https://console.firebase.google.com/) та створіть новий безкоштовний проєкт.
   - Створіть **Realtime Database** у режимі тестування (`test mode`).
   - У налаштуваннях проєкту скопіюйте **Database URL** або повний конфіг `firebaseConfig` і вставте в налаштуваннях додатку.

*Примітка:* Якщо Firebase не підключено, додаток буде працювати у локальному режимі, зберігаючи дані в пам'яті браузера (`localStorage`).
