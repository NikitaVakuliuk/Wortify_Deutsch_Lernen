# 🇩🇪 Wortyfi_Deutsch_Lernen — PWA Тренажер німецьких слів з ШІ та Хмарою

Сучасний веб-додаток для вивчення німецьких слів із використанням штучного
інтелекту Google Gemini та миттєвою хмарною синхронізацією через Firebase.

## 🚀 Основні можливості

- **Картки Лейтнера (Spaced Repetition):** 5 рівнів засвоєння слів, 3D-анімація
  та озвучення.
- **Генератор & Magic Autofill (Gemini 3.8 Flash):** Автоматичний добір слів за
  рівнями (A1–C1) та автозаповнення форм слів (артиклі, множина, 3 форми
  дієслів, приклади та їх українські переклади).
- **Синхронізація між пристроями:** Хмарна база даних (Firebase Realtime DB) з
  можливістю автономної роботи в `localStorage`.
- **Тренажери:** Тестування (Quiz) з підтримкою умлаутів та гра «З'єднай пари».
- **Керування словником:** Пошук, імпорт/експорт у `.json` та генерація
  оновленого `words.js`.

## 🛠️ Як підключити власну хмару та ШІ

1. Відкрийте додаток і натисніть іконку **Налаштувань ⚙️** у правому верхньому
   кутку.

2. **Підключення ШІ (Gemini API):**
   - Отримайте безкоштовний ключ на
     [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Вставте його в поле `Google Gemini API Key`.

3. **Підключення хмари (Firebase Realtime Database):**
   - Зайдіть на [Firebase Console](https://console.firebase.google.com/) та
     створіть новий проєкт.
   - Створіть **Realtime Database**.
   - Перейдіть у вкладку **Rules (Правила)** бази даних і вкажіть відкритий
     доступ для читання та запису (щоб додаток працював без авторизації):
     ```json
     {
       "rules": {
         ".read": true,
         ".write": true
       }
     }
     ```
   - Натисніть **Publish (Опублікувати)**.
   - Скопіюйте **Database URL** (або весь `firebaseConfig` з налаштувань
     проєкту) і вставте в налаштуваннях додатку.

_Примітка:_ Якщо Firebase не підключено, додаток працює у локальному режимі,
зберігаючи всі дані в пам'яті браузера (`localStorage`).
